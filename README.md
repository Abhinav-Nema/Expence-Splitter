# 💸 Expense Splitter Web App

This is a full-stack **Expense Splitter** application designed to simplify managing shared expenses for groups. Built with a **Django REST Framework** backend and a clean, dynamic frontend using vanilla **HTML, CSS, and JavaScript**, this app calculates who owes whom and minimizes the number of transactions needed to settle debts.

---

## ✨ Key Features

* **Group Management**: Create groups and easily add or remove members.
* **Expense Tracking**: Log expenses, specifying who paid and which members were involved.
* **Smart Settlement**: A custom algorithm automatically calculates balances and generates a simplified list of payments to clear all debts.
* **API-Driven**: A comprehensive REST API for managing groups, members, expenses, and settlements.
* **Dynamic Frontend**: A responsive user interface that interacts with the backend in real-time using the Fetch API.

---

## 💻 Tech Stack

* **Backend**: Python, Django, Django REST Framework
* **Frontend**: HTML, CSS, JavaScript
* **Database**: SQLite
